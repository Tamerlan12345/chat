# CentyChat

Корпоративный мессенджер с сервером, настольным клиентом и нативными клиентами [Android](mobile/android/README.md) и [iOS](mobile/ios/README.md).

## Статус мобильных клиентов на 2026-10-08

| Клиент | Статус реализации | Проверено | Что ещё требуется для выпуска |
| --- | --- | --- | --- |
| Android | Функциональная реализация завершена; новые функции пока на паузе | Unit-тесты, lint, debug APK и debug AndroidTest APK прошли локально и в CI; инструментальные тесты эмулятора в CI прошли на merge-коммите `6fe90ed` | Подписанная release-сборка с ключом владельца, установка и сценарии на физическом устройстве, реальные FCM credentials и доставка push |
| iOS | Функциональная реализация завершена; новые функции пока на паузе | Сборка, unit-тесты, UI-сценарий на симуляторе и проверка привязки Release к серверу проходили в CI; полный iOS simulator CI и проверка Release на merge-коммите `6fe90ed` прошли | Apple signing и установка на физический iPhone/iPad, реальные APNs и доставка push |

«Реализация завершена» здесь означает готовность исходного кода для проверенных сценариев. Это не означает, что мобильные приложения готовы к публикации или что все требования OWASP MASVS подтверждены. Во время паузы выполняются аудит безопасности и выпускные проверки; найденные дефекты исправляются. Текущее состояние и открытые условия описаны в [отчёте по безопасности](docs/security_best_practices_report.md) и [чек-листе выпуска](docs/RELEASE-CHECKLIST.md).

Тестовый Railway-сервис временно носит имя среды `production`. Он развёрнут вручную из `master`; привязки GitHub source repo сейчас нет, поэтому один лишь push в `master` сервер не обновляет.
