## Decisions required before publication or console entry

1. Confirm legal controller name, address, contact, lawful bases, jurisdiction, support and privacy URLs, and corporate distribution channel.
2. Identify actual server host/subprocessors, processing countries, logs and backup arrangements, retention schedule, and data-request handling. The repository does not establish a deployment-wide retention or erasure promise.
3. Inspect the exact signed Android/iOS artifacts, merged manifests, SDK privacy disclosures, release server settings, and push credentials. Current source alone cannot certify store form answers or operational push.
4. Confirm Google Play's sharing/service-provider and location-from-IP classifications; confirm Apple Device ID, Other User Content, audit/usage type and purpose mappings. Reconcile the iOS privacy manifest if its categories need to change.
5. Provide a reviewer-accessible, non-production server and disposable accounts, and verify physical-device permissions and notification behavior before any Apple review notes are submitted.
