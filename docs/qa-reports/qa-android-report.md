## Дефекты
- D1 (Major) Нет ресинхронизации после обрыва сети. Повтор: открыть список чатов -> включить авиарежим -> Боб шлёт сообщение (POST /api/messages/direct/2) -> выключить авиарежим, ждать 15+ с. Баннер уходит, но превью/бейдж в списке и открытый чат не обновляются; сообщение видно только после перезахода в чат; счётчик непрочитанных занижен (1 вместо 2 при 2 пропущенных + live-сообщении...). Живые сообщения после реконнекта идут нормально.
- D2 (Major) Сообщение, отправленное в оффлайне, молча теряется: композер очищается, пузыря/ошибки/статуса "не отправлено" нет, на сервере его нет (search q=offline -> []), после реконнекта не уходит. Повтор: авиарежим, ввести текст, Отправить. s26.png. Ожидается: очередь либо статус ошибки с повтором (TC-SYNC).
- D3 (Minor) Шрифт 2.0: подписи нижней навигации обрезаны ("Объявлени", "Профиль" упирается в край), поле поиска "Люди, каналы, сообщ…". d2.png. Нижние вкладки при таком шрифте плохо нажимаются.
- D4 (Minor/Missing) Вложения: тап по файлу в чате не открывает/не скачивает (открывается контекстное меню). Отправка файлов с Android тоже недоступна (нет UI выбора файла).
- D5 (Minor) Поиск: после закрытия клавиатуры (Back) поле поиска сохраняет запрос, но экран показывает обычный список чатов, а не результаты; после "Очистить" и нового ввода результаты не появляются, пока не тапнуть поле заново. s20.png.
- D6 (Trivial) Англоязычные a11y-строки "Close sheet", "Drag handle" в листе объявления.
- D7 (Trivial) Тап по пузырю сообщения сразу открывает меню Ответить/Удалить (нет Редактировать/Копировать); Back с главного экрана при открытом пустом поиске сворачивает приложение (ожидаемо, но поиск не закрылся первым Back).
- D8 (Trivial/UX) Запрос POST_NOTIFICATIONS показывается до входа, без объяснения.
- Наблюдения: админ в списке "в сети" без подключения (серверная метка presence); typing-фрейм шлётся на каждый символ (около 14 за ввод 25 знаков) - стоит троттлить.

## Нереализовано на Android
Регистрация; блокировка пользователя / жалоба на пользователя/сообщение; удаление аккаунта; смена имени/аватара/пароля в профиле (смена пароля только принудительная); открытие/загрузка вложений.
