## Как запустить окружение на новом компьютере

- Сервер: `server/`, `npm ci`, `.env` по `.env.example`, тесты `npm test` (≈790 тестов), аудит `npm audit --omit=dev --audit-level=high` (CI требует 0).
- Desktop: `desktop/`, `npm ci`, `npm test` (≈470), запуск в разработке; сборка Windows через electron-builder.
- Android: нужны JDK 17 и Android SDK (compileSdk 36, образ эмулятора API 34 google_apis x86_64). Gradle на 16 ГБ памяти: только `--max-workers=2 -Dorg.gradle.jvmargs=-Xmx1536m` и с закрытым эмулятором. Юнит-тесты: `gradlew testDebugUnitTest`. Dev-стенд для приложения: `mobile/dev/stand.mjs` (сервер + TLS-прокси 8443, debug-сборка ходит на `https://10.0.2.2:8443`, доверяет dev-CA; демо-пользователи — `mobile/dev/seed.mjs`, только для разработки).
- iOS: макоса нет, проверка только в GitHub Actions (`mobile-ios`, macos-15, симулятор iPhone 16); артефакты: `ios-simulator-test-results`, `ios-ui-video`.
- CI: `gh run list --branch mobile-release-parity-impl`; три проверки — `security-checks`, `mobile-android`, `mobile-ios`. Раньше нестабильно падал `security-checks` (джоб `secrets`/Windows-раннер) — повторный запуск проходил.
